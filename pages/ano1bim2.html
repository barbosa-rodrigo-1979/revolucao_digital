🎯 Título

"O Algoritmo Invisível" ou "Como uma linha de código decide o que você vai pensar hoje (e você nem sabia que estava sendo programado)"

🎯 Objetivos Operacionais

  • Compreender o conceito de algoritmo como sequência lógica de passos e sua onipresença no cotidiano digital.
  • Identificar como algoritmos de recomendação funcionam nas principais plataformas (YouTube, TikTok, Instagram, Spotify, Netflix).
  • Analisar criticamente o viés algorítmico e o efeito bolha como mecanismos de controle de atenção.
  • Simular o papel de um algoritmo de recomendação em um jogo de curadoria.
  • Bônus: entender que algoritmo não é mágica é matemática disfarçada de decisão e, muitas vezes, interesse econômico travestido de neutralidade.

📚 Conteúdo Programático

  • O que é um algoritmo? Definição, exemplos do cotidiano (receitas, rotas, instruções) e sua presença invisível na vida digital.
  • Algoritmos de recomendação Como eles "sabem" o que você gosta: coleta de dados, histórico, comportamento, interações.
  • O viés algorítmico Por que algoritmos não são neutros: eles refletem os vieses de quem os programou e dos dados com que foram treinados.
  • O efeito bolha (filter bubble) Como você fica preso no que já concorda e deixa de ver o que é diferente.
  • Curadoria algorítmica vs. curadoria humana Quem decide o que você vê? Uma máquina ou uma pessoa com critérios?
  • O papel dos dados de treinamento Como vieses históricos e culturais são incorporados aos algoritmos.
  • A economia política dos algoritmos Quem lucra com o que você vê? Por que o algoritmo te mostra isso e não aquilo?

💻 Código Comentado

Esta seção apresenta um exemplo prático de código que os alunos poderão explorar, comentado linha a linha para compreensão do funcionamento de um algoritmo de recomendação simplificado. 

# ============================================================
# ALGORITMO DE RECOMENDAÇÃO SIMPLIFICADO (VERSÃO DIDÁTICA)
# ============================================================
#
# Este código simula, de forma extremamente simplificada, como
# um algoritmo de recomendação decide o que mostrar para um usuário.
#
# NA VIDA REAL: milhões de variáveis, redes neurais, dados
# massivos e interesses bilionários.
# AQUI: só para entender a lógica por trás da "mágica".
# ============================================================

# 1. BANCO DE DADOS DO USUÁRIO (o que o algoritmo "sabe" sobre você)
# Na vida real, isso vem do seu histórico de navegação, curtidas,
# tempo de visualização, localização, dispositivo, hora do dia...

usuario = {
    "nome": "João",
    "idade": 16,
    "interesses": ["futebol", "jogos", "humor"],  # baseado no que ele curtiu
    "historico": [  # o que ele já assistiu/curtiu
        {"titulo": "Melhores gols de 2024", "categoria": "futebol", "curtiu": True},
        {"titulo": "Gameplay de Minecraft", "categoria": "jogos", "curtiu": True},
        {"titulo": "Receita de bolo de chocolate", "categoria": "culinaria", "curtiu": False},
    ]
}

# 2. BANCO DE DADOS DE CONTEÚDO (o que o algoritmo pode te mostrar)
# Na vida real: milhões de vídeos, posts, anúncios, músicas...

conteudos = [
    {"id": 1, "titulo": "Golaço de falta - Brasileirão 2025", "categoria": "futebol"},
    {"id": 2, "titulo": "Tutorial de Python para iniciantes", "categoria": "programacao"},
    {"id": 3, "titulo": "Melhores momentos - Copa do Mundo", "categoria": "futebol"},
    {"id": 4, "titulo": "Novo jogo da Rockstar - análise", "categoria": "jogos"},
    {"id": 5, "titulo": "Como fazer miojo gourmet", "categoria": "culinaria"},
    {"id": 6, "titulo": "Prank com amigos - pegadinha épica", "categoria": "humor"},
    {"id": 7, "titulo": "Documentário sobre mudanças climáticas", "categoria": "ciencia"},
]

# 3. FUNÇÃO DE RECOMENDAÇÃO (o coração do algoritmo)
# É aqui que a "mágica" acontece. Na vida real, isso é uma
# rede neural com bilhões de parâmetros. Aqui, é uma simples
# contagem de interesses em comum.

def recomendar(usuario, conteudos):
    """
    Recomenda conteúdos com base nos interesses do usuário.
    PASSO A PASSO (ALGORITMO):
    1. Para cada conteúdo disponível...
    2. ...conte quantos interesses do usuário ele atende.
    3. Ordene os conteúdos do mais relevante para o menos relevante.
    4. Retorne os 3 primeiros (top 3).
    """
    # DECOMPOSIÇÃO: vamos analisar cada conteúdo individualmente
    recomendacoes = []
    for conteudo in conteudos:
        # RECONHECIMENTO DE PADRÕES: o conteúdo tem algo a ver
        # com os interesses do usuário?
        pontuacao = 0
        # Verifica se a categoria do conteúdo está nos interesses do usuário
        if conteudo["categoria"] in usuario["interesses"]:
            pontuacao += 1  # cada interesse compatível = +1 ponto
        # Verifica se o usuário já curtiu algo similar no histórico
        for item in usuario["historico"]:
            if item["categoria"] == conteudo["categoria"] and item["curtiu"]:
                pontuacao += 0.5  # curtiu algo similar = +0.5 ponto
        recomendacoes.append({
            "conteudo": conteudo,
            "pontuacao": pontuacao
        })
    # ALGORITMO: ordenar do maior para o menor (os mais relevantes primeiro)
    recomendacoes.sort(key=lambda x: x["pontuacao"], reverse=True)
    # ABSTRAÇÃO: retornamos apenas os 3 melhores (simplificamos o resultado)
    return recomendacoes[:3]

# 4. EXECUTANDO O ALGORITMO
print("=" * 50)
print("🤖 ALGORITMO DE RECOMENDAÇÃO EM AÇÃO")
print("=" * 50)
print(f"\n👤 Usuário: {usuario['nome']}")
print(f"📌 Interesses: {', '.join(usuario['interesses'])}")
print(f"📜 Histórico: {len(usuario['historico'])} itens")
print("\n⏳ Processando...")
print("-" * 50)

resultados = recomendar(usuario, conteudos)

print("\n🎯 TOP 3 RECOMENDAÇÕES:")
for i, resultado in enumerate(resultados, 1):
    conteudo = resultado["conteudo"]
    print(f"\n{i}. {conteudo['titulo']}")
    print(f"   📂 Categoria: {conteudo['categoria']}")
    print(f"   ⭐ Relevância: {resultado['pontuacao']} pontos")

print("\n" + "=" * 50)
print("💡 REFLEXÃO:")
print("- O algoritmo te mostrou o que você QUER ver,")
print("  não necessariamente o que você PRECISA ver.")
print("- Se você só vê futebol, vai achar que o mundo")
print("  inteiro só fala de futebol. Isso é uma BOLHA.")
print("=" * 50)

  • O que são dados pessoais? Nome, idade, localização, interesses, histórico de navegação, lista de contatos, fotos, mensagens, hábitos de consumo, biometria...

  • Estudo de caso: Cambridge Analytica Como dados de 87 milhões de pessoas foram usados para manipular eleições (EUA 2016, Brexit).
  • O modelo de negócio das plataformas Dados + anúncios = dinheiro. Quanto mais dados, mais dinheiro. Quanto mais tempo de tela, mais dados.

class ColetorDeDados:
    """
    Simula a coleta de dados de um usuário.
    Na vida real, isso é feito por cookies, pixels de rastreamento,
    SDKs de terceiros, e centenas de outras tecnologias invisíveis.
    """
    def __init__(self):
        # Banco de dados do usuário (começa vazio)
        self.dados_usuario = {
            "informacoes_basicas": {},
            "comportamento": [],
            "interesses": [],
            "localizacao": [],
            "dispositivos": []
        }

    def coletar_dados_basicos(self, nome, idade, genero, cidade):
        """
        Coleta dados que você fornece "voluntariamente" ao se cadastrar.
        """
        self.dados_usuario["informacoes_basicas"] = {
            "nome": nome,
            "idade": idade,
            "genero": genero,
            "cidade": cidade,
            "data_coleta": "hoje"  # na vida real: timestamp exato
        }
        print(f"📥 Coletados dados básicos de {nome}")

    def rastrear_clique(self, item, categoria, tempo_gasto):
        """
        Rastreia o que você clica, quanto tempo você gasta,
        e o que isso diz sobre você.
        """
        registro = {
            "item": item,
            "categoria": categoria,
            "tempo_gasto": tempo_gasto,  # em segundos
            "timestamp": "agora"
        }
        self.dados_usuario["comportamento"].append(registro)
        # Atualiza interesses com base no comportamento
        if categoria not in self.dados_usuario["interesses"]:
            self.dados_usuario["interesses"].append(categoria)
        print(f"🖱️ Clique rastreado: {item} ({categoria}) - {tempo_gasto}s")

    def rastrear_localizacao(self, latitude, longitude):
        """
        Rastreia onde você está. Sim, seu celular faz isso o tempo todo.
        """
        self.dados_usuario["localizacao"].append({
            "lat": latitude,
            "lon": longitude,
            "timestamp": "agora"
        })
        print(f"📍 Localização registrada: {latitude}, {longitude}")

    def obter_perfil(self):
        """
        Constrói o perfil do usuário com base em todos os dados coletados.
        Este é o "clone digital" que a plataforma vende para anunciantes.
        """
        perfil = {
            "nome": self.dados_usuario["informacoes_basicas"].get("nome", "Anônimo"),
            "idade": self.dados_usuario["informacoes_basicas"].get("idade", "Desconhecida"),
            "cidade": self.dados_usuario["informacoes_basicas"].get("cidade", "Desconhecida"),
            "interesses_identificados": list(set(self.dados_usuario["interesses"])),
            "total_cliques": len(self.dados_usuario["comportamento"]),
            "tempo_medio_por_clique": self._calcular_tempo_medio(),
            "locais_visitados": len(self.dados_usuario["localizacao"]),
            "classificacao_anunciante": self._classificar_para_anuncios()
        }
        return perfil

    def _calcular_tempo_medio(self):
        """Calcula o tempo médio gasto por clique."""
        if not self.dados_usuario["comportamento"]:
            return 0
        total = sum(registro["tempo_gasto"] for registro in self.dados_usuario["comportamento"])
        return total / len(self.dados_usuario["comportamento"])

    def _classificar_para_anuncios(self):
        """
        Classifica o usuário para segmentação de anúncios.
        Isso é o que as plataformas VENDEM.
        """
        interesses = set(self.dados_usuario["interesses"])
        if "futebol" in interesses and "jogos" in interesses:
            return "PÚBLICO ALVO: Jovens gamers + esportes"
        elif "moda" in interesses or "beleza" in interesses:
            return "PÚBLICO ALVO: Moda e estilo de vida"
        elif "tecnologia" in interesses or "programacao" in interesses:
            return "PÚBLICO ALVO: Tech enthusiasts"
        else:
            return "PÚBLICO ALVO: Geral (menos valioso para anunciantes)"

import random
import time

class PlataformaDeAtencao:
    """
    Simula uma plataforma de rede social que usa gatilhos
    emocionais para maximizar o tempo de tela do usuário.
    """
    def __init__(self, nome):
        self.nome = nome
        self.gatilhos_ativos = []
        self.tempo_total = 0
        self.interacoes = 0

    def ativar_gatilho(self, gatilho):
        """
        Ativa um gatilho emocional na plataforma.
        Cada gatilho é uma estratégia de design para te prender.
        """
        self.gatilhos_ativos.append(gatilho)
        print(f"🔔 Gatilho ativado: {gatilho['nome']}")
        print(f"   Descrição: {gatilho['descricao']}")

    def simular_uso(self, minutos):
        """
        Simula o uso da plataforma por X minutos.
        A cada interação, um gatilho é acionado.
        """
        print(f"\n📱 Usando {self.nome} por {minutos} minutos...")
        print("-" * 50)
        for minuto in range(minutos):
            # A cada minuto, um gatilho pode ser acionado
            if random.random() < 0.4:  # 40% de chance por minuto
                gatilho = random.choice(self.gatilhos_ativos)
                self._acionar_gatilho(gatilho)
                self.interacoes += 1
            self.tempo_total += 1
            time.sleep(0.1)  # só para efeito de simulação
        print("-" * 50)
        print(f"⏱️ Tempo total: {self.tempo_total} minutos")
        print(f"🔄 Interações: {self.interacoes}")

    def _acionar_gatilho(self, gatilho):
        """
        Aciona um gatilho emocional específico.
        Cada gatilho tem um efeito psicológico diferente.
        """
        print(f"\n⚡ GATILHO ACIONADO: {gatilho['nome']}")
        print(f"   {gatilho['efeito']}")
        # Alguns gatilhos têm efeitos colaterais (ansiedade, FOMO, etc.)
        if gatilho['nome'] == "Notificação":
            print("   🔴 Você recebeu uma notificação! (você precisa ver agora)")
        elif gatilho['nome'] == "Rolagem Infinita":
            print("   🔄 Mais conteúdo está carregando... e mais... e mais...")
        elif gatilho['nome'] == "Curtidas":
            print("   ❤️ Alguém curtiu sua foto! (você se sente validado)")
        elif gatilho['nome'] == "Comparação Social":
            print("   👀 Seu amigo está viajando! (por que você não está lá?)")
        elif gatilho['nome'] == "FOMO":
            print("   😱 Você está perdendo algo importante! (todo mundo está vendo)")
        elif gatilho['nome'] == "Recompensa Variável":
            print("   🎰 Você ganhou um prêmio! (mas só se continuar rolando)")

# ============================================================
# SIMULADOR DE DESENVOLVIMENTO DE PROTÓTIPO
# ============================================================
#
# Este código simula o processo de desenvolvimento de um
# protótipo de conscientização digital.
#
# O objetivo: mostrar como o planejamento se transforma em
# código, design e impacto.
# ============================================================

import time
import random

# ============================================================
# 1. CLASSE BASE: PROTÓTIPO
# ============================================================
class Prototipo:
    """
    Classe base para todos os protótipos.
    """
    def __init__(self, nome, descricao, objetivo, publico_alvo):
        self.nome = nome
        self.descricao = descricao
        self.objetivo = objetivo
        self.publico_alvo = publico_alvo
        self.estado = "planejado"
        self.tarefas = []
        self.concluido = False
        self.bugs = []

    def adicionar_tarefa(self, tarefa):
        """Adiciona uma tarefa ao desenvolvimento."""
        self.tarefas.append({"tarefa": tarefa, "status": "pendente"})
        print(f"📋 Tarefa adicionada: {tarefa}")

    def executar_tarefa(self, tarefa):
        """Executa uma tarefa específica."""
        for t in self.tarefas:
            if t["tarefa"] == tarefa and t["status"] == "pendente":
                print(f"🔨 Executando: {tarefa}")
                time.sleep(0.5)  # simula o trabalho
                # 20% de chance de encontrar um bug
                if random.random() < 0.2:
                    bug = f"Bug em {tarefa}"
                    self.bugs.append(bug)
                    print(f"🐛 BUG ENCONTRADO: {bug}")
                    print("   Corrigindo...")
                    time.sleep(0.3)
                    print("   ✅ Bug corrigido!")
                t["status"] = "concluida"
                print(f"✅ Tarefa concluída: {tarefa}")
                return True
        print(f"❌ Tarefa '{tarefa}' não encontrada ou já concluída")
        return False

    def verificar_progresso(self):

        total = len(self.tarefas)

        progresso = (concluidas / total * 100) if total > 0 else 0
        print(f"\n📊 PROGRESSO: {progresso:.1f}% ({concluidas}/{total} tarefas)")
        if self.bugs:
            print(f"🐛 Bugs corrigidos: {len(self.bugs)}")
        return progresso

    def finalizar(self):
        """Finaliza o protótipo."""
        if self.verificar_progresso() == 100:
            self.estado = "concluido"
            self.concluido = True
            print("\n🎉 PROTÓTIPO FINALIZADO COM SUCESSO!")
            print(f"   Nome: {self.nome}")
            print(f"   Objetivo: {self.objetivo}")
            print(f"   Público-alvo: {self.publico_alvo}")
            return True
        else:
            print("\n⚠️ Protótipo ainda não está 100% completo.")
            print(" Continue trabalhando!")
            return False

# O objetivo: mostrar que todo projeto passa por iterações

import random
import time

# ============================================================
# 1. SIMULADOR DE TESTES
# ============================================================
class Testador:
    """
    Simula o processo de testes de um protótipo.
    """
    def __init__(self, prototipo):
        self.prototipo = prototipo
        self.resultados = []
        self.bugs_encontrados = []
        self.melhorias_sugeridas = []

    def testar_funcionalidade(self):
        """
        Testa se o protótipo faz o que deveria fazer.
        """
        print("\n🔧 TESTE DE FUNCIONALIDADE")
        print("-" * 40)
        print("Verificando se o protótipo funciona como esperado...")
        # Simula a execução de testes
        testes = [
            "Inicialização do sistema",
            "Execução da função principal",
            "Resposta a entradas do usuário",
            "Processamento de dados",
            "Geração de saída"
        ]
        falhas = 0
        for teste in testes:
            # 80% de chance de passar
            if random.random() < 0.8:
                print(f" ✅ {teste}: OK")
            else:
                print(f" ❌ {teste}: FALHOU")
                falhas += 1
                bug = f"Falha em {teste}"
                self.bugs_encontrados.append(bug)
        if falhas == 0:
            print("\n✅ Todos os testes de funcionalidade passaram!")
        else:
            print(f"\n⚠️ {falhas} teste(s) falharam. Bugs identificados.")
        return falhas == 0

    def testar_usabilidade(self):
        """
        Testa se o protótipo é fácil de usar.
        """
        print("\n👤 TESTE DE USABILIDADE")
        print("-" * 40)
        print("Verificando se o protótipo é intuitivo e fácil de usar...")
        aspectos = [
            "Interface clara e organizada",
            "Instruções compreensíveis",
            "Navegação intuitiva",
            "Feedback ao usuário",
            "Tempo de resposta adequado"
        ]
        problemas = 0
        for aspecto in aspectos:
            # 75% de chance de estar bom
            if random.random() < 0.75:
                print(f" ✅ {aspecto}: OK")
            else:
                print(f" ⚠️ {aspecto}: PODE MELHORAR")
                problemas += 1
                melhoria = f"Melhorar {aspecto.lower()}"
                self.melhorias_sugeridas.append(melhoria)
        if problemas == 0:
            print("\n✅ Usabilidade excelente!")
        else:
            print(f"\n💡 {problemas} aspecto(s) podem ser melhorados.")
        return problemas == 0

    def testar_acessibilidade(self):
        """
        Testa se o protótipo é acessível.
        """
        print("\n♿ TESTE DE ACESSIBILIDADE")
        print("-" * 40)
        print("Verificando se o protótipo é acessível a todos...")
        criterios = [
            "Suporte a leitores de tela",
            "Contraste adequado",
            "Fontes legíveis",
            "Navegação por teclado",
            "Descrições de imagens"
        ]
        problemas = 0
        for criterio in criterios:
            # 70% de chance de estar OK
            if random.random() < 0.7:
                print(f" ✅ {criterio}: OK")
            else:
                print(f" ⚠️ {criterio}: PODE MELHORAR")
                problemas += 1
                melhoria = f"Melhorar {criterio.lower()}"
                self.melhorias_sugeridas.append(melhoria)
        if problemas == 0:
            print("\n✅ Acessibilidade excelente!")
        else:
            print(f"\n💡 {problemas} aspecto(s) de acessibilidade podem ser melhorados.")
        return problemas == 0

    def executar_testes(self):
        """
        Executa todos os testes.
        """
        print("\n" + "=" * 60)
        print("🧪 INICIANDO BATERIA DE TESTES")
        print("=" * 60)
        resultados = {
            "funcionalidade": self.testar_funcionalidade(),
            "usabilidade": self.testar_usabilidade(),
            "acessibilidade": self.testar_acessibilidade()
        }
        print("\n" + "=" * 60)
        print("📊 RESUMO DOS TESTES")
        print("=" * 60)
        for teste, passou in resultados.items():
            status = "✅ PASSou" if passou else "❌ FALHOU"
            print(f" {teste.capitalize()}: {status}")
        if self.bugs_encontrados:
            print(f"\n🐛 Bugs encontrados: {len(self.bugs_encontrados)}")
            for bug in self.bugs_encontrados:
                print(f" - {bug}")
        if self.melhorias_sugeridas:
            print(f"\n💡 Melhorias sugeridas: {len(self.melhorias_sugeridas)}")
            for melhoria in self.melhorias_sugeridas:
                print(f" - {melhoria}")
        return resultados

class Refinador:
    """
    Simula o processo de refinamento do protótipo.
    """
    def __init__(self, prototipo, testador):
        self.prototipo = prototipo
        self.testador = testador
        self.iteracoes = 0

    def refinar(self):
        """
        Refina o protótipo com base nos resultados dos testes.
        """
        self.iteracoes += 1
        print(f"\n🔨 ITERAÇÃO DE REFINAMENTO {self.iteracoes}")
        print("=" * 60)

        # Corrigir bugs
        if self.testador.bugs_encontrados:
            print("\n🐛 CORRIGINDO BUGS...")
            for bug in self.testador.bugs_encontrados:
                print(f" 🔧 Corrigindo: {bug}")
                time.sleep(0.3)
                print(f" ✅ Bug corrigido!")
            self.testador.bugs_encontrados = []

        # Implementar melhorias
        if self.testador.melhorias_sugeridas:
            print("\n💡 IMPLEMENTANDO MELHORIAS...")
            for melhoria in self.testador.melhorias_sugeridas:
                print(f" 🚀 Implementando: {melhoria}")
                time.sleep(0.3)
                print(f" ✅ Melhoria implementada!")
            self.testador.melhorias_sugeridas = []

        print("\n✅ Refinamento concluído!")

        # Verificar se o protótipo está pronto
        if not self.testador.bugs_encontrados and not self.testador.melhorias_sugeridas:
            print("\n🎉 PROTÓTIPO PRONTO PARA O PITCH!")
            return True
        else:
            print("\n⚠️ Ainda há trabalho a fazer. Continue refinando!")
            return False

💻 Código Comentado

Esta seção apresenta um código que simula uma apresentação de pitch para que os alunos entendam, na prática, como estruturar uma apresentação impactante. 

# ============================================================
# SIMULADOR DE PITCH A GRANDE ESTREIA
# ============================================================
#
# Este código simula uma apresentação de pitch no formato
# Shark Tank / Pitch Night.
#
# O objetivo: mostrar como estruturar uma apresentação
# convincente e impactante.
# ============================================================

import time

# ============================================================
# 1. ESTRUTURA DO PITCH
# ============================================================
class Pitch:
    """
    Estrutura uma apresentação de pitch de 3 minutos.
    """
    def __init__(self, nome_projeto, problema, solucao, publico_alvo, impacto):
        self.nome_projeto = nome_projeto
        self.problema = problema
        self.solucao = solucao
        self.publico_alvo = publico_alvo
        self.impacto = impacto
        self.segmentos = []
        self._construir_pitch()

    def _construir_pitch(self):
        """Constrói os segmentos do pitch."""
        self.segmentos = [
            {
                "nome": "Abertura Impactante",
                "duracao": 20,  # segundos
                "conteudo": f"🚀 Olá! Somos o grupo e hoje vamos apresentar o {self.nome_projeto}."
            },
            {
                "nome": "O Problema",
                "duracao": 40,
                "conteudo": f"📌 O problema que identificamos: {self.problema}. Isso afeta {self.publico_alvo} e tem impactos reais."
            },
            {
                "nome": "A Solução",
                "duracao": 50,
                "conteudo": f"💡 Nossa solução: {self.solucao}. Ela funciona porque..."
            },
            {
                "nome": "Demonstração",
                "duracao": 40,
                "conteudo": "🎬 Agora, vamos demonstrar o protótipo em ação!"
            },
            {
                "nome": "Impacto",
                "duracao": 30,
                "conteudo": f"📊 O impacto esperado: {self.impacto}. E aqui estão os dados que comprovam..."
            },
            {
                "nome": "Fechamento",
                "duracao": 20,
                "conteudo": "🎯 Por que vocês deveriam acreditar nisso? Porque nós acreditamos. E porque isso importa."
            }
        ]

    def apresentar(self):
        """Simula a apresentação do pitch."""
        print("=" * 60)
        print(f"🎤 PITCH: {self.nome_projeto}")
        print("=" * 60)
        print("\n⏱️ Tempo total: 3 minutos (180 segundos)")
        print("\n" + "-" * 60)
        total_tempo = 0
        for segmento in self.segmentos:
            print(f"\n📌 {segmento['nome']} ({segmento['duracao']}s)")
            print(f"   {segmento['conteudo']}")
            total_tempo += segmento['duracao']
            time.sleep(0.2)  # simula o tempo de apresentação
        print("\n" + "-" * 60)
        print(f"\n✅ Pitch concluído! Tempo total: {total_tempo}s")
        print("\n🤝 Agora, perguntas da banca!")

# ============================================================
# 2. SIMULAÇÃO DE BANCA (PERGUNTAS E RESPOSTAS)
# ============================================================
class Banca:
    """
    Simula uma banca avaliadora que faz perguntas sobre o projeto.
    """
    def __init__(self):
        self.perguntas = [
            {
                "pergunta": "Qual foi o maior desafio que vocês enfrentaram durante o desenvolvimento?",
                "dica": "Seja honesto. Mostre que aprenderam com os desafios."
            },
            {
                "pergunta": "Como vocês sabem que essa solução realmente funciona?",
                "dica": "Mostre evidências: testes, feedback de usuários, dados."
            },
            {
                "pergunta": "O que vocês fariam diferente se tivessem mais tempo?",
                "dica": "Mostre que vocês pensam no futuro e na melhoria contínua."
            },
            {
                "pergunta": "Qual é o próximo passo? O que vem depois do protótipo?",
                "dica": "Mostre visão de futuro. O projeto não termina aqui."
            },
            {
                "pergunta": "Por que vocês escolheram esse problema?",
                "dica": "Mostre que o problema é relevante e pessoal para vocês."
            }
        ]

    def fazer_perguntas(self):
        """Simula a sessão de perguntas e respostas."""
        print("\n" + "=" * 60)
        print("❓ SESSÃO DE PERGUNTAS E RESPOSTAS")
        print("=" * 60)
        print("\nA banca vai fazer algumas perguntas. Respondam com confiança!")
        for i, item in enumerate(self.perguntas, 1):
            print(f"\n📌 PERGUNTA {i}: {item['pergunta']}")
            print(f"   💡 Dica: {item['dica']}")
            print("   🤔 (Pausa para resposta do grupo)")
            time.sleep(0.5)
        print("\n" + "=" * 60)
        print("✅ Sessão de perguntas concluída!")
        print(" Parabéns, grupo! Vocês mandaram bem!")

# ============================================================
# 3. AUTOAVALIAÇÃO
# ============================================================
class Autoavaliacao:
    """
    Simula o processo de autoavaliação após a apresentação.
    """
    def __init__(self):
        self.perguntas = [
            "O que eu aprendi com este projeto?",
            "O que foi mais difícil?",
            "O que eu faria diferente?",
            "O que eu mais curti no processo?",
            "Como eu me sinto agora?"
        ]

    def refletir(self):
        """Guia a reflexão individual."""
        print("\n" + "=" * 60)
        print("📝 AUTOAVALIAÇÃO")
        print("=" * 60)
        print("\nReserve um momento para refletir sobre sua jornada:")
        for pergunta in self.perguntas:
            print(f"\n❓ {pergunta}")
            print("   (Escreva sua resposta em seu caderno/diário)")
        print("\n" + "=" * 60)
        print("💡 LEMBRE-SE:")
        print(" O projeto é importante, mas o que você")
        print(" se tornou para construí-lo é ainda mais.")
        print("=" * 60)

# ============================================================
# 4. SIMULAÇÃO
# ============================================================
print("=" * 60)
print("🎬 SIMULADOR DE PITCH A GRANDE ESTREIA")
print("=" * 60)
print("\n⚠️ ATENÇÃO: Isso é uma SIMULAÇÃO de uma")
print(" apresentação de pitch.")
print(" Na vida real, vai ser ainda mais emocionante!")
print("=" * 60)

# Criando o pitch
pitch = Pitch(
    nome_projeto="App: 'Tempo de Tela Consciente'",
    problema="Jovens passam em média 4+ horas por dia em redes sociais, com impactos negativos na saúde mental.",
    solucao="Um app que monitora o uso do celular e envia alertas personalizados para pausas conscientes.",
    publico_alvo="Adolescentes e jovens adultos (15-25 anos)",
    impacto="Redução de 30% no tempo de tela e melhora na qualidade do sono."
)

# Apresentando o pitch
pitch.apresentar()

# Sessão de perguntas
banca = Banca()
banca.fazer_perguntas()

# Autoavaliação
autoavaliacao = Autoavaliacao()
autoavaliacao.refletir()

print("\n" + "=" * 60)
print("🎉 PARABÉNS! VOCÊ CONCLUIU O PITCH!")
print("=" * 60)
print("\nA jornada foi longa, o código foi escrito,")
print("os bugs foram exterminados.")
print("Agora, o que importa não é o site que vocês construíram")
print("--- é o que vocês se tornaram para construí-lo.")
print("\n🚀 Vocês são incríveis. Continuem assim.")

⏱️ Detalhamento Minuto a Minuto (50 min)

Minuto Atividade Descrição
0-5 Abertura Épica 🎬 Professor inicia com uma trilha sonora épica (tema de filme) e uma saudação: "Hoje é o dia. O dia em que vocês mostram ao mundo o que construíram. Não é sobre o código é sobre a história que vocês têm para contar."
5-10 Preparação Final ⏳ Últimos ajustes, verificação de que tudo está funcionando. Nervosismo e empolgação. "Respirem fundo. Vocês estão prontos."
10-40 Apresentações das Equipes 🎤 Cada equipe tem 3 minutos para apresentar: (1) O que é o projeto, (2) Demonstração ao vivo, (3) Desafios e aprendizados. A turma aplaude após cada apresentação. Formato Shark Tank.
40-43 Feedback Coletivo 🗣️ A turma discute: "Quais projetos mais chamaram atenção? O que foi inspirador? O que surpreendeu?"
43-46 Votação e Premiação 🏆 Votação em categorias: 🏆 Mais Criativo, 🧠 Mais Técnico, 🎨 Mais Bonito, 🤯 Mais Impactante, ❤️ Mais Empático. Entrega de certificados simbólicos.
46-48 Autoavaliação 📝 Cada aluno preenche um formulário rápido de autoavaliação: "O que aprendi? O que foi difícil? O que faria diferente? O que mais curti?"
48-50 Fechamento Emocional 🚀 Professor faz um discurso de encerramento: "Vocês são incríveis. Construíram, erraram, aprenderam, evoluíram. Lembrem-se: o código é só a ferramenta. O que importa é o que vocês criam com ela. E, mais importante, quem vocês se tornam para criá-la. Parabéns, guerreiros digitais! 🚀"

ORIENTAÇÕES PARA ADAPTAÇÕES E INCLUSÃO

"Um projeto que só funciona para um tipo de pessoa não é um projeto – é um clube exclusivo. E a gente não faz clubes exclusivos."

Deficiência Visual
  • Use leitores de tela (NVDA), braille, descrições táteis, programação por voz e Lego Braille Bricks.
  • Garanta alto contraste e fontes grandes (mínimo 16px).
Deficiência Auditiva
  • Garanta legendas completas em vídeos, intérprete de Libras (quando disponível), transcrições escritas e uso de chat para debates.
Deficiência Motora
  • Divida em sprints curtos (15-20 min), use checklists visuais, cronômetros e papéis claramente definidos nos grupos.
  • Garanta navegação por teclado e botões com tamanho adequado (mínimo 44px).
TDAH
  • Use roteiros sociais, cronogramas visuais, perguntas enviadas com antecedência e ambiente com poucos estímulos sensoriais.
Altas Habilidades
  • Ofereça desafios extras, projetos ampliados (complexidade técnica), mentoria e produção de conteúdo aprofundado (artigos, pesquisas).
