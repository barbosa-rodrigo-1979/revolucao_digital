📢 TEXTO DE ABERTURA: O MANIFESTO DA REVOLUÇÃO

ATTENTION, ZUMBIS DIGITAIS! 🧟‍♂️

Esqueçam o que acham que sabem sobre a internet. Esqueçam o feed. Esqueçam o like. Esqueçam a dopamina barata que vocês recebem cada vez que um coraçãozinho vermelho aparece na tela.

Vocês acham que são LIVRES? Que escolhem o que veem? Que são DONOS dos próprios dados? Que são donos de alguma coisa, aliás?

HAHAHAHAHAHA.

Não, meus caros. Vocês são produtos. São matéria-prima. São gado digital sendo ordenhado por meia dúzia de bilionários que vocês ajudaram a enriquecer enquanto rolavam a tela sem fim.

Mas calma. Não é o fim do mundo.

É o COMEÇO.

Este ano, vocês não vão "estudar" tecnologia vocês vão DESMONTAR a Matrix. Vão descobrir como o algoritmo te transformou em um zumbi. Vão entender que seus dados valem mais do que o rim que vocês venderiam por um iPhone novo. Vão construir CASTELOS DIGITAIS com suas próprias mãos (e muito teclado). E, no final, vão CRIAR o mundo digital que vocês querem ver não o que foi vendido para vocês.

Vão passar de produto a produtor. De consumidor a criador. De zumbi a arquiteto.

📦 BIMESTRE 1: "CODANDO O FUTURO" A Construção do Castelo Digital

SEMANA 1 "O Universo HTML: A Estrutura do Nada"

🎯 Título: "O Universo HTML: A Estrutura do Nada" ou "Como construir um castelo com tags e sem tijolos"

🎯 Objetivos Operacionais:

  • Compreender o que é HTML e seu papel fundamental na construção de páginas web
  • Identificar e utilizar tags estruturais: <!DOCTYPE html>, <html>, <head>, <body>
  • Utilizar tags de conteúdo: <h1> a <h6>, <p>, <ul>, <ol>, <li>
  • Criar uma página funcional a partir do zero

🧩 Pilares do Pensamento Computacional:

  • Abstração: HTML representa uma página de forma estruturada, escondendo a complexidade do navegador
  • Reconhecimento de Padrões: Identificação do padrão de abertura e fechamento de tags

📋 Atividade Principal: Construir a primeira página HTML coletiva, com títulos, parágrafos e listas de coisas proibidas (ou permitidas)

📊 Avaliação:

  • Estrutura Básica (0-3): Criou o arquivo .html com <!DOCTYPE>, <html>, <head>, <body>, <title>
  • Tags de Conteúdo (0-3): Usou pelo menos 3 tags diferentes de conteúdo
  • Personalização (0-2): Modificou o conteúdo com criatividade
  • Indentação (0-1): Código organizado e indentado
  • Ajuda aos Colegas (0-1): Contribuiu com a turma

SEMANA 2 "CSS: A Maquiagem dos Deuses"

🎯 Título: "CSS: A Maquiagem dos Deuses" ou "Como transformar um monstro do Frankenstein em uma supermodelo digital"

🎯 Objetivos Operacionais:

  • Compreender o papel do CSS na estilização e na experiência visual
  • Aplicar seletores básicos: elemento, classe e ID
  • Utilizar propriedades de cor, fonte, espaçamento, borda e sombra
  • Aplicar CSS nas formas inline, interno e externo

🧩 Pilares do Pensamento Computacional:

  • Reconhecimento de Padrões: Identificação do padrão seletor { propriedade: valor; }
  • Decomposição: Dividir a estilização em partes isoladas

📋 Atividade Principal: "Operação Tapa na Cara do Feio" cada dupla recebe uma página "feia" e precisa estilizá-la para ficar impactante

📊 Avaliação:

  • Vínculo do CSS (0-2): Conseguiu vincular o arquivo .css ao HTML
  • Uso de Seletores (0-3): Aplicou os 3 tipos de seletor
  • Propriedades Essenciais (0-3): Usou pelo menos 5 propriedades diferentes
  • Personalização Criativa (0-2): A estilização tem personalidade

SEMANA 3 "JavaScript: A Mágica Acontece"

🎯 Título: "JavaScript: A Mágica Acontece" ou "Como fazer o computador obedecer aos seus caprichos"

🎯 Objetivos Operacionais:

  • Compreender o papel do JS na interatividade
  • Utilizar variáveis, tipos (string, number, boolean) e operadores
  • Criar funções simples
  • Manipular o HTML via JS (document.getElementById().innerHTML)

🧩 Pilares do Pensamento Computacional:

  • Decomposição: Gerar desculpas aleatórias = (1) criar array, (2) sortear índice, (3) exibir
  • Algoritmos: Sequência lógica de passos para executar a tarefa

📋 Atividade Principal: Criar um "Gerador de Desculpas Esfarrapadas" botão que exibe uma desculpa aleatória para não fazer lição

📊 Avaliação:

  • Array de Desculpas (0-2): Criou o array com pelo menos 5 desculpas
  • Função Funcional (0-3): A função gerarDesculpa() está implementada
  • Sorteio Aleatório (0-2): Usou Math.random() e Math.floor()
  • Manipulação do DOM (0-2): Usou document.getElementById() e .innerHTML

SEMANA 4 "DOM: O Documento que Vive"

🎯 Título: "DOM: O Documento que Vive" ou "Como ter controle remoto sobre cada pedacinho da sua página"

🎯 Objetivos Operacionais:

  • Entender o DOM como uma árvore que representa a página
  • Usar getElementById, querySelector, querySelectorAll
  • Modificar atributos, classes e estilos via JS
  • Criar e remover elementos dinamicamente

🧩 Pilares do Pensamento Computacional:

  • Algoritmos: Sequência para selecionar, modificar e criar elementos
  • Abstração: O DOM esconde a complexidade do renderizador

📋 Atividade Principal: "Caça ao Elemento" desafio de selecionar e modificar elementos via JS

📊 Avaliação:

  • Seleção de Elementos (0-2): Usou pelo menos 2 métodos diferentes
  • Manipulação de Estilos (0-2): Modificou estilos ou classes
  • Criação Dinâmica (0-2): Criou elemento com createElement e appendChild
  • Remoção de Elementos (0-1): Removeu elementos

SEMANA 5 "Eventos: Quando o Usuário Toca na Tela"

🎯 Título: "Eventos: Quando o Usuário Toca na Tela" ou "Como fazer seu site reagir a tudo cliques, teclas e até respirações"

🎯 Objetivos Operacionais:

  • Entender eventos (click, keydown, mouseover, mouseout)
  • Usar addEventListener() (a forma moderna e recomendada)
  • Construir um jogo da memória completo

🧩 Pilares do Pensamento Computacional:

  • Decomposição: Cada interação (virar carta, verificar par, desvirar) é uma parte do jogo
  • Algoritmos: Sequência lógica para cada ação do jogador

📋 Atividade Principal: Construir um "Jogo da Memória do Caos" com emojis e eventos

📊 Avaliação:

  • Uso de addEventListener (0-3): Utilizou para pelo menos 3 eventos
  • Lógica do Jogo (0-3): Funciona corretamente
  • Eventos de Teclado (0-1): Implementou atalho
  • Feedback ao Usuário (0-1): Fornece feedback visual

📢 TEXTO DE ENCERRAMENTO: O DESPERTAR

E aí, zumbis digitais. Acordaram?

Passou um ano. Quatro bimestres. 40 semanas. Centenas de linhas de código. Milhares de cliques. Bugs que fizeram vocês quererem jogar o computador pela janela. Acertos que fizeram vocês se sentirem deuses.

Vocês começaram o ano achando que a internet era um lugar mágico onde tudo era grátis e ninguém ganhava nada com a presença de vocês.

HAHAHAHA. Que inocentes.

Agora vocês sabem. Sabem que o algoritmo é um deus caprichoso que decide o que vocês veem. Sabem que seus dados valem mais que ouro. Sabem que a atenção de vocês é o produto mais valioso do mundo. Sabem que a bolha digital é real e que vocês estavam dentro dela.

Mas, mais importante: vocês sabem construir. Sabem codificar. Sabem criar. Sabem QUEBRAR a Matrix e construir algo novo. Algo que coloca pessoas no centro, não lucro. Algo que conecta, não aliena. Algo que liberta, não aprisiona.

Vocês passaram de consumidores a criadores. De produtos a produtores. De zumbis a arquitetos.

O mundo digital nunca mais será o mesmo.

E vocês nunca mais serão os mesmos.

A revolução foi codificada.

E vocês foram os programadores.

Parabéns, guerreiros digitais. 🚀

Agora, vão. Hackeiem o mundo. Criem o futuro. E lembrem-se: o código é só a ferramenta. O que importa é o que vocês criam com ele.
