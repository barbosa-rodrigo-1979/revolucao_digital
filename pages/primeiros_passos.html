VSCODE – O CANIVETE SUÍÇO DOS DEUSES DA PROGRAMAÇÃO

Manual Extremamente Detalhado para Iniciantes (que vão usar HTML, CSS, JS e Python)

PARTE 1: O QUE É ESSA FERRAMENTA E POR QUE VOCÊ DEVE AMAR ELA

Bem-vindo ao Matrix, Neo.

Sabe aquela cena do Matrix onde o Neo finalmente vê o código por trás da realidade? Pois é. O VSCode é o seu óculos de realidade aumentada para programação – só que sem precisar tomar pílulas estranhas de um cara de barba.

O Visual Studio Code (ou VSCode, pros íntimos) é um editor de código open-source criado pela Microsoft. E antes que você torça o nariz: sim, a Microsoft. A mesma que fez o Internet Explorer. Mas dessa vez eles acertaram. Acertaram tanto que o VSCode é hoje o editor mais amado do planeta pelos programadores. É tipo a redenção do Darth Vader, só que em forma de software.

Mas por que ele é tão foda?

  • É de graça. Não, sério. 100% gratuito. Nem pegadinha. Pode baixar, instalar, usar, amar.
  • Funciona em tudo: Windows, Mac, Linux – não importa se você é time Microsoft, maçã mordida ou pinguim.
  • Leve e rápido. Ele não é aquela bazuca chamada Visual Studio (o irmão mais velho bombado que pesa 50GB e demora uma eternidade pra abrir). O VSCode abre em segundos.
  • Extensões pra tudo quanto é lado. Quer programar em Python? Tem extensão. Em JavaScript? Tem. Em HTML/CSS? Tem. Em linguagem de signo? Provavelmente tem também.
  • Inteligência artificial integrada. O GitHub Copilot tá lá, pronto pra te ajudar a escrever código como se você tivesse um sênior de 20 anos de experiência olhando por cima do seu ombro.
  • Debugger embutido. Você vai errar. Muito. E o VSCode vai estar lá pra te ajudar a descobrir ONDE você errou.

O que você vai construir com ele?

Com o VSCode, você vai:

  • Escrever HTML (a estrutura dos sites – tipo os ossos do esqueleto)
  • Escrever CSS (a beleza, o estilo – tipo a roupa e maquiagem)
  • Escrever JavaScript (a mágica, a interatividade – tipo o cérebro que faz as coisas acontecerem)
  • Escrever Python (a linguagem versátil que serve pra tudo, desde site até inteligência artificial)

E tudo isso no MESMO lugar. Sem precisar ficar alternando entre 15 programas diferentes. É tipo ter um canivete suíço com 500 funções, só que na tela do seu computador.

PARTE 2: INSTALAÇÃO – BAIXANDO O PODER

Passo 1: Baixe o bichinho

Abra seu navegador (Chrome, Firefox, Edge, ou aquele navegador estranho que você usa pra baixar jogos) e vá para:

👉 https://code.visualstudio.com/

O site é inteligente: ele já detecta qual é o seu sistema operacional e mostra o botão de download certo. Se não detectar, você pode escolher manualmente:

Seu Sistema O que baixar
Windows .exe (o instalador normal)
Mac .dmg (o instalador da Apple)
Linux .deb, .rpm ou .tar.gz (depende da sua distribuição)

Passo 2: Instale como um adulto responsável

No Windows:

  1. Clique duas vezes no arquivo .exe baixado
  2. Concorde com os termos (ninguém lê mesmo, mas clica em “Aceito”)
  3. Escolha a pasta de instalação (ou deixe a padrão, não seja rebelde)
  4. IMPORTANTE: Na tela “Selecionar Tarefas Adicionais”, marque TODAS as opções, especialmente:
    • ☑️ Adicionar “Abrir com Code” ao menu de contexto
    • ☑️ Registrar Code como editor para tipos de arquivo suportados
    • ☑️ Adicionar à variável PATH (isso é super importante pra rodar comandos)
  5. Clique em “Instalar” e espere. Vai tomar um café. Ou dois.

No Mac:

  1. Clique duas vezes no arquivo .dmg
  2. Arraste o ícone do VSCode para a pasta “Applications”
  3. Pronto. Sim, é só isso. A Apple gosta de fazer parecer fácil.

No Linux (Ubuntu/Debian):

sudo dpkg -i code_.deb
# ou, se tiver Snap
sudo snap install --classic code

Passo 3: Abra pela primeira vez

Abra o VSCode. Você vai ver uma janela com uma cara mais ou menos assim:

  • Barra de Atividades (do lado esquerdo) com ícones bonitinhos
  • Editor (no meio) – a área gigante onde a mágica acontece
  • Barra de Status (embaixo) com informações úteis

Se aparecer uma tela de boas-vindas, aproveite pra dar uma olhada. Mas se você é do tipo “pular tutorial e sair batendo”, pode fechar. A gente volta lá depois.

🔥 BÔNUS: Configure o terminal integrado

O VSCode vem com um terminal integrado que é uma maravilha. Você não precisa ficar alternando entre o editor e o CMD/PowerShell/Terminal.

Para abrir:

  • Windows/Linux: Ctrl + ` (crase, a tecla do lado do 1)
  • Mac: Cmd + ` (crase)

PARTE 3: A INTERFACE – CONHECENDO OS BOTÕES MÁGICOS

O Layout: Um tour guiado

Imagine que o VSCode é uma nave espacial. Você é o piloto. Vamos conhecer o painel de controle:

1. A Barra de Atividades (lado esquerdo)

É aquela coluna vertical com ícones. De cima pra baixo:

Ícone Nome O que faz
📁 Explorer Mostra seus arquivos e pastas
🔍 Search Procura texto em todos os arquivos
🔀 Source Control Controle de versão (Git)
🐛 Run and Debug Roda e depura seu código
🧩 Extensions Loja de extensões – a parte mais divertida
👤 Accounts Suas contas (GitHub, Microsoft)
⚙️ Manage Configurações, temas, etc

2. O Editor (centro)

É a área gigante. Aqui você escreve código. Você pode abrir VÁRIOS arquivos ao mesmo tempo, cada um em sua própria aba. Pode até dividir a tela em duas, três, quatro partes – tipo um jogo de Tetris, mas produtivo.

3. A Barra de Status (embaixo)

Mostra informações úteis como:

  • Qual linguagem você está usando
  • Em qual branch do Git você está
  • Quantos problemas o código tem (spoiler: vai ter muitos)
  • Encoding do arquivo
  • Tamanho do arquivo

4. O Painel (embaixo do editor)

É onde aparecem:

  • Terminal 🖥️ – seu amigo das horas vagas
  • Problemas ⚠️ – os erros que você vai cometer
  • Saída 📤 – logs e mensagens
  • Console de Debug 🐛 – pra quando você está caçando bugs

O Comando Supremo: Command Palette

Essa é a coisa mais importante que você vai aprender hoje. Sério. É tipo o “Avada Kedavra” do VSCode.

Pressione:

  • Windows/Linux: Ctrl + Shift + P
  • Mac: Cmd + Shift + P

Isso abre a Command Palette. É uma caixinha de busca que permite ACESSAR QUALQUER FUNÇÃO do VSCode sem precisar ficar clicando em menus.

  • Quer abrir um arquivo? Digite “Open” e escolha.
  • Quer mudar o tema? Digite “Theme” e escolha.
  • Quer instalar uma extensão? Digite “Extensions” e escolha.
  • Quer fazer café? Bem… essa ainda não tem, mas vai que na próxima versão.

DECORE ISSO: Ctrl/Cmd + Shift + P é seu novo melhor amigo. Use e abuse.

PARTE 4: EXTENSÕES – TORNANDO O VSCODE UM SUPER-EDITOR

O VSCode “puro” já é bom. Mas com extensões, ele vira uma nave espacial com turbo, laser e piloto automático.

Como instalar extensões

  1. Clique no ícone de 🧩 Extensions na barra de atividades (ou Ctrl+Shift+X)
  2. Digite o nome da extensão que você quer
  3. Clique em “Install”
  4. Pronto. É literalmente isso.

As extensões OBRIGATÓRIAS pra você

Para HTML/CSS/JavaScript:

Extensão O que faz
Live Server Abre seu HTML no navegador com atualização automática – você muda o código, a página recarrega sozinha. É mágico.
Prettier Formata seu código automaticamente. Adeus, bagunça. Olá, código bonito.
Auto Rename Tag Muda a tag de abertura e a de fechamento juntas. Se você mudar <div> pra <section>, a fechação </div> vira </section> automaticamente.
ESLint Aponta erros de JavaScript antes mesmo de você rodar o código.
HTML CSS Support Autocomplete pra classes CSS dentro do HTML.
Path Intellisense Autocomplete pra caminhos de arquivos.

Para Python:

Extensão O que faz
Python (da Microsoft) A extensão definitiva. Dá IntelliSense, debug, linting, formatação, testes – TUDO.
Pylance O interpretador de Python que faz o autocomplete funcionar como mágica.
Python Indent Corrige indentação automaticamente (coisa que todo iniciante em Python sofre).

Extras que você vai amar:

Extensão O que faz

Todo Tree Mostra todos os TODO: e FIXME: do seu código num lugar só.

PARTE 5: SEU PRIMEIRO PROJETO – MÃO NA MASSA

Agora a coisa fica séria. Vamos criar seu primeiro projeto. E não, não vai ser um “Hello World” genérico – vai ser uma página de portfólio maneira.

Passo 1: Crie uma pasta pro projeto

No seu computador, crie uma pasta chamada meu-primeiro-projeto. Pode ser na área de trabalho, nos documentos, onde você quiser.

Passo 2: Abra a pasta no VSCode

No VSCode:

  • Clique em File > Open Folder (ou Arquivo > Abrir Pasta)
  • Navegue até sua pasta e selecione

Pronto. Agora a pasta aparece no Explorer do VSCode.

Passo 3: Crie seus arquivos

No Explorer (lado esquerdo), clique no ícone de “New File” (ou botão direito > New File) e crie:

  1. index.html – a página principal
  2. style.css – os estilos
  3. script.js – a interatividade
  4. app.py – o Python (porque sim, vamos misturar tudo)

Passo 4: Escreva o HTML

No index.html, escreva:

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Eu, Programador</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>🚀 Olá, mundo!</h1>
  <p>Este é meu primeiro projeto no VSCode.</p>
  <button id="botao-magico">Clique aqui</button>
  <script src="script.js"></script>
</body>
</html>

Passo 5: Escreva o CSS

No style.css:

body {
  font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
  max-width: 600px;
  margin: 50px auto;
  padding: 20px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  color: white;
  text-align: center;
}
button {
  background: white;
  color: #764ba2;
  border: none;
  padding: 15px 30px;
  font-size: 18px;
  border-radius: 30px;
  cursor: pointer;
  transition: transform 0.3s;
}
button:hover {
  transform: scale(1.1);
}

Passo 6: Escreva o JavaScript

No script.js:

document.getElementById('botao-magico').addEventListener('click', function() {
  alert('🎉 Você clicou! O VSCode é demais!');
});

Passo 7: Escreva o Python

No app.py:

print("🐍 Olá do Python!")
nome = input("Qual é o seu nome? ")
print(f"Bem-vindo ao VSCode, {nome}!")

PARTE 6: RODANDO O CÓDIGO – HORA DO SHOW

Rodar HTML com Live Server

  1. Instale a extensão Live Server (se já não instalou)
  2. Com o index.html aberto, clique com o botão direito no editor
  3. Escolha “Open with Live Server”
  4. Seu navegador abre automaticamente com a página
  5. Qualquer mudança no código atualiza a página instantaneamente

É tipo mágica, mas é tecnologia.

Rodar JavaScript

Se seu JS está no HTML (ou conectado via <script src="">), o Live Server já executa.

Se quiser rodar JS puro no terminal:

  1. Instale o Node.js (se não tiver)
  2. Abra o terminal integrado (Ctrl + `)
  3. Rode: node script.js

Rodar Python

  1. Instale a extensão Python da Microsoft
  2. Com o app.py aberto, clique no triângulo ▶️ no canto superior direito
  3. Ou use o terminal: python app.py

O VSCode automaticamente detecta seu interpretador Python e roda o código.

PARTE 7: DEBUGANDO – CAÇANDO BUGS COMO UM PROFISSIONAL

Você vai errar. Todo mundo erra. O importante é saber encontrar os erros.

Como debugar no VSCode

  1. Clique no ícone 🐛 da barra de atividades (Run and Debug)
  2. Clique em “Run and Debug” (ou F5)
  3. Escolha o ambiente (Python, Node.js, etc)
  4. O VSCode cria um arquivo launch.json com a configuração

Colocando breakpoints

Breakpoints são “pontos de parada” – o código para naquela linha e você pode inspecionar tudo.

Para colocar um:

  • Clique na margem esquerda do editor (ao lado do número da linha)
  • Aparece uma bolinha vermelha 🔴

Quando o código chegar naquele ponto, ele PARA. Aí você pode:

  • Ver valores de variáveis
  • Ver a call stack (quem chamou quem)
  • Ver o que está na memória

PARTE 8: CONFIGURAÇÕES – DEIXANDO DO SEU JEITO

Mudando o tema

O tema padrão é bonito, mas você pode mudar:

  1. Ctrl/Cmd + Shift + P
  2. Digite “Color Theme”
  3. Escolha um: Dark+, Light+, Solarized, One Dark Pro, etc

Configurações importantes

Abra as configurações (Ctrl+, ou Cmd+,) e ajuste:

Configuração O que faz Recomendação
editor.fontSize Tamanho da fonte 16 (seus olhos agradecem)
editor.fontFamily Fonte do código 'Fira Code', 'Cascadia Code' (fontes com ligaturas)
editor.wordWrap Quebrar linhas longas "on"
editor.minimap.enabled Mapa do código true (ajuda a navegar)
editor.renderWhitespace Mostrar espaços "all" (ajuda a ver espaços extras)
workbench.colorTheme Tema "Dark Modern" ou "One Dark Pro"

Configurações via JSON

Se você é old-school, pode editar o arquivo JSON diretamente:

  1. Ctrl/Cmd + Shift + P
  2. Digite “Open User Settings (JSON)”
  3. Adicione suas configurações:
{
  "editor.fontSize": 16,
  "editor.fontFamily": "'Fira Code', 'Cascadia Code', monospace",
  "editor.fontLigatures": true,
  "workbench.colorTheme": "One Dark Pro",
  "editor.minimap.enabled": true
}

PARTE 9: CONTROLE DE VERSÃO – GIT INTEGRADO

O VSCode tem Git integrado. Você não precisa sair do editor pra dar commit.

Inicializar um repositório

  1. Abra a aba Source Control (🔀)
  2. Clique em “Initialize Repository”
  3. Seu projeto agora está sob controle de versão

Fazer commit

  1. Faça alterações nos arquivos
  2. Na aba Source Control, os arquivos aparecem como modificados
  3. Clique no + ao lado de cada arquivo (stage)
  4. Escreva uma mensagem de commit
  5. Clique em Commit

Publicar no GitHub

  1. Clique em “Publish Branch”
  2. Escolha se quer público ou privado
  3. Pronto. Seu código tá no GitHub

PARTE 12: DICAS E TRUQUES QUE NINGUÉM TE CONTA

  1. Preview do Markdown – Se você escrever arquivos .md, clique no ícone de “Open Preview” no canto superior direito. Você vê o Markdown renderizado ao vivo.
  2. Zen Mode – Ctrl+K Z (ou Cmd+K Z no Mac) entra no modo ZEN – tela cheia, sem distrações. Só você e o código.
  3. Emmet no HTML – Digite div.container>ul>li*3 e aperte Tab. O VSCode expande para: 
    <div class="container">
  <ul>
    <li></li>
    <li></li>
    <li></li>
  </ul>
</div>
  4. Snippets – Digite ! num arquivo HTML e aperte Tab. O VSCode gera a estrutura HTML completa. Obrigado, snippets.
  5. Command Palette com fuzzy search – Na Command Palette, você não precisa digitar o nome exato. Digite “the” e aparece “Color Theme”. O VSCode é inteligente.
  6. Abrir arquivos com Ctrl+P – Ctrl+P (ou Cmd+P) é mais rápido que ficar navegando pelo Explorer. Digite o nome do arquivo e aperte Enter.
  7. Comparar arquivos – Selecione dois arquivos no Explorer, clique com o botão direito e escolha “Compare Selected”. O VSCode mostra as diferenças lado a lado.

PARTE 13: PERGUNTAS FREQUENTES (FAQ)

P: O VSCode é realmente grátis?
R: Sim. 100% grátis. Não tem pegadinha. A Microsoft ganha dinheiro com o GitHub e o Copilot, não com o VSCode.
P: Preciso saber programar pra usar?
R: Não. O VSCode é uma ferramenta. Você vai aprender programando. É tipo perguntar se precisa saber dirigir pra comprar um carro.
P: Qual a diferença entre VSCode e Visual Studio?
R: O Visual Studio é um IDE pesadão pra desenvolvimento enterprise (C#, .NET, etc). O VSCode é um editor leve e versátil. Pense no Visual Studio como um caminhão e no VSCode como uma bicicleta que você pode turbinar com extensões.
P: Posso usar VSCode pra outras linguagens além das que você falou?
R: SIM! Tem extensão pra C, C++, Java, Go, Rust, PHP, Ruby, Swift, Kotlin… basicamente qualquer linguagem que existe.
P: O VSCode tem suporte a IA?
R: Tem o GitHub Copilot integrado. Se você assinar (ou usar a versão grátis com limite mensal), ele sugere código enquanto você digita. É tipo ter um parceiro de programação.
P: Posso sincronizar minhas configurações entre computadores?
R: Sim! Com o Settings Sync, você loga com sua conta GitHub ou Microsoft e todas as configurações, extensões e temas sincronizam automaticamente.

Erros comuns e como resolver

– Você não instalou o Python
– Baixe em python.org e instale

PARTE 15: BÔNUS – COMO PARECER UM PROGRAMADOR PROFISSIONAL

  1. Use temas escuros. É clichê, mas funciona. Dark Modern, One Dark Pro, Dracula – todos são aceitáveis.
  2. Use fontes com ligaturas. Fira Code, Cascadia Code, JetBrains Mono. Elas transformam != em ≠ e => em ⇒. Parece mágica.
  3. Decore os atalhos. Não precisa saber todos, mas saber os principais (Command Palette, abrir arquivos, terminal) te faz parecer um ninja.
  4. Use o terminal integrado. Nada grita “sou profissional” como abrir o terminal dentro do editor em vez de abrir um CMD separado.
  5. Faça commits frequentes. Git integrado + commits com mensagens boas = você parece um sênior.
  6. Personalize. Mude o tema, instale extensões, configure atalhos. Seu VSCode é seu. Faça dele sua casa.

📦 INSTALAÇÃO NO WINDOWS – O PASSO A PASSO QUE NINGUÉM TE DEU

Escolhendo seu instalador: User vs System vs ZIP

O VSCode no Windows vem em três sabores:

✨ EMMET – O SUPER-PODER QUE VOCÊ NÃO SABIA QUE PRECISAVA

O que é Emmet?

Emmet é um sistema de abreviações que transforma textos curtos em estruturas HTML e CSS completas. Ele já vem integrado no VSCode, sem precisar instalar nada.

Emmet é suportado nativamente em arquivos .html, .css, .scss, .jsx e vários outros.

Como funciona?

Você digita uma abreviação e aperta Tab (ou Enter) – o VSCode expande pra estrutura completa.

Atalhos básicos de HTML

Abreviação Expande para
! + Tab Estrutura HTML5 completa

link:css + Tab <link rel="stylesheet" href="style.css">
script:src + Tab <script src=""></script>
ul>li*5 + Tab Lista não ordenada com 5 itens
div.container + Tab <div class="container"></div>
header+main+footer + Tab Três elementos irmãos

Exemplos na prática

1. Estrutura básica: Digite ! e aperte Tab. O VSCode gera:

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
</head>
<body>
</body>
</html>

2. Div com classe e filho: Digite div.container>h1{Olá Mundo} e aperte Tab. Gera:

<div class="container">
  <h1>Olá Mundo</h1>
</div>

3. Lista com itens: Digite ul>li.item*3 e aperte Tab. Gera:

<ul>
  <li class="item"></li>
  <li class="item"></li>
  <li class="item"></li>
</ul>

</header>

  <section></section>
  <section></section>

</main>

  <p></p>
</footer>

<a href="https://google.com">Clique aqui</a>

Abreviação Expande para

Por padrão, o Emmet é acionado com Tab nos arquivos HTML e CSS. Se por algum motivo não estiver funcionando, você pode ativar explicitamente:

"emmet.includeLanguages": {

}

Com isso, Emmet funciona em JSX e inclusive converte class para className automaticamente.

🌐 LIVE SERVER – SEU HTML RODANDO EM TEMPO REAL

O que é o Live Server?

O Live Server é uma extensão que cria um servidor de desenvolvimento local e atualiza o navegador automaticamente sempre que você salva um arquivo.

Ou seja: você muda o código, salva, e o navegador recarrega sozinho. Sem F5, sem clicar em refresh, sem perder o foco.

Instalando o Live Server

  1. Abra a aba de extensões (🧩) ou pressione Ctrl + Shift + X
  2. Busque por “Live Server”
  3. Instale a extensão do Ritwick Dey (é a mais popular)

Usando o Live Server

Com o arquivo HTML aberto:

  1. Clique com o botão direito no editor
  2. Escolha “Open with Live Server”

Ou use o atalho:

  • Windows/Linux: Alt + L, Alt + O
  • Mac: Cmd + L, Cmd + O

O navegador abre com sua página em um endereço tipo http://127.0.0.1:5500.

O que acontece quando você edita?

  1. Você faz uma alteração no HTML, CSS ou JS
  2. Pressiona Ctrl + S (salva)
  3. O Live Server detecta a mudança
  4. O navegador recarrega automaticamente

Isso é game-changer. Você não perde tempo alternando entre editor e navegador. O foco fica no código.

Dicas do Live Server

  • Porta: O padrão é 5500. Se estiver ocupada, ele usa 5501, 5502, etc.
  • Abrir no navegador: Se você já tiver a página aberta, ele só recarrega.
  • Dispositivos móveis: O servidor roda na sua rede local. Pegue seu celular, digite http://[SEU-IP]:5500 e veja sua página no celular em tempo real.
  • Parar o servidor: Olhe na barra de status (embaixo). Tem um botão “Port: 5500” – clique e escolha “Stop Live Server”.

🌍 AMBIENTES VIRTUAIS – ISOLANDO SEUS PROJETOS

O que é um ambiente virtual?

Um ambiente virtual é uma cópia isolada do Python dentro do seu projeto. Cada projeto tem seu próprio Python, suas próprias bibliotecas, suas próprias versões.

Por que isso é importante?

  • Projeto A precisa da versão 1.0 da biblioteca X
  • Projeto B precisa da versão 2.0 da biblioteca X
  • Sem ambientes virtuais, você teria que desinstalar e instalar toda hora
  • Com ambientes virtuais, cada projeto tem sua própria versão

É tipo cada projeto ter seu próprio quarto, com suas próprias coisas, sem bagunçar o quarto dos outros.

Criando um ambiente virtual com venv

O Python vem com o módulo venv pra criar ambientes virtuais.

No terminal integrado do VSCode (dentro da pasta do seu projeto), rode:

python -m venv .venv

Isso cria uma pasta .venv dentro do seu projeto com uma cópia isolada do Python.

Ativando o ambiente virtual

  • No Windows (PowerShell): .venv\Scripts\Activate.ps1
  • No Windows (CMD): .venv\Scripts\activate.bat
  • No Mac/Linux: source .venv/bin/activate

Quando o ambiente está ativo, você vê (.venv) no início do prompt do terminal.

Selecionando o interpretador no VSCode

O VSCode detecta automaticamente ambientes virtuais com o nome .venv na raiz do projeto.

Mas se não detectar, você pode selecionar manualmente:

  1. Abra a Command Palette (Ctrl + Shift + P ou Cmd + Shift + P)
  2. Digite “Python: Select Interpreter”
  3. Escolha o interpretador que está dentro da pasta .venv

O VSCode mostra na barra de status (embaixo) qual interpretador está sendo usado.

Instalando pacotes no ambiente virtual

Com o ambiente ativado, use o pip para instalar pacotes:

pip install requests
pip install flask
pip install numpy pandas

Os pacotes são instalados apenas dentro do .venv, não afetam o resto do sistema.

O arquivo requirements.txt

Para compartilhar as dependências do seu projeto:

pip freeze > requirements.txt

Isso cria um arquivo com todas as bibliotecas instaladas e suas versões.

Outra pessoa pode instalar tudo com:

pip install -r requirements.txt

Calculadora simples em Python
Demonstra funções, input do usuário e tratamento de erros
"""

def soma(a, b):
    return a + b

def subtracao(a, b):
    return a - b

def multiplicacao(a, b):
    return a * b

def divisao(a, b):
    if b == 0:
        return "Erro: divisão por zero!"
    return a / b

def calculadora():
    print("🧮 CALCULADORA PYTHON")
    print("=" * 30)
    while True:
        print("\nOperações:")
        print("1 - Soma")
        print("2 - Subtração")
        print("3 - Multiplicação")
        print("4 - Divisão")
        print("5 - Sair")
        opcao = input("\nEscolha uma opção: ")
        if opcao == "5":
            print("👋 Até logo!")
            break
        if opcao not in ["1", "2", "3", "4"]:
            print("❌ Opção inválida!")
            continue
        try:
            num1 = float(input("Digite o primeiro número: "))
            num2 = float(input("Digite o segundo número: "))
        except ValueError:
            print("❌ Entrada inválida! Digite números.")
            continue
        if opcao == "1":
            resultado = soma(num1, num2)
            print(f"✅ {num1} + {num2} = {resultado}")
        elif opcao == "2":
            resultado = subtracao(num1, num2)
            print(f"✅ {num1} - {num2} = {resultado}")
        elif opcao == "3":
            resultado = multiplicacao(num1, num2)
            print(f"✅ {num1} × {num2} = {resultado}")
        elif opcao == "4":
            resultado = divisao(num1, num2)
            print(f"✅ {num1} ÷ {num2} = {resultado}")

if __name__ == "__main__":
    calculadora()

🐍 BACKEND – CRIANDO A API COM FLASK

O que é Flask?

Flask é um micro-framework para Python. Ele permite criar servidores web e APIs REST com poucas linhas de código. É leve, flexível e perfeito para projetos como este.

Passo 1: Crie e ative o ambiente virtual

No terminal integrado (dentro da pasta todo-app):

python -m venv .venv

Ative:

  • Windows: .venv\Scripts\activate
  • Mac/Linux: source .venv/bin/activate

Passo 2: Instale o Flask

pip install flask

Passo 3: Crie o arquivo requirements.txt

No terminal, rode:

pip freeze > backend/requirements.txt

Isso salva as dependências. Sempre faça isso para compartilhar o projeto.

Passo 4: Escreva o backend

No arquivo backend/app.py, cole o código abaixo:

from flask import Flask, jsonify, request, render_template

app = Flask(__name__)

# Dados em memória (simulando um banco de dados)
tarefas = []
contador_id = 1

@app.route('/')
def home():
    return "🚀 Servidor Flask está rodando! Acesse /tarefas para ver a lista."

@app.route('/tarefas', methods=['GET'])
def listar_tarefas():
    """Retorna todas as tarefas em formato JSON"""
    return jsonify(tarefas)

@app.route('/tarefas', methods=['POST'])
def criar_tarefa():
    """Cria uma nova tarefa"""
    global contador_id
    dados = request.get_json()
    if not dados or 'titulo' not in dados:
        return jsonify({'erro': 'Título é obrigatório'}), 400
    nova_tarefa = {
        'id': contador_id,
        'titulo': dados['titulo'],
        'concluida': False
    }
    tarefas.append(nova_tarefa)
    contador_id += 1
    return jsonify(nova_tarefa), 201

@app.route('/tarefas/', methods=['PUT'])
def atualizar_tarefa(id):
    """Atualiza uma tarefa (marca como concluída ou não)"""
    dados = request.get_json()
    for tarefa in tarefas:
        if tarefa['id'] == id:
            if 'titulo' in dados:
                tarefa['titulo'] = dados['titulo']
            if 'concluida' in dados:
                tarefa['concluida'] = dados['concluida']
            return jsonify(tarefa)
    return jsonify({'erro': 'Tarefa não encontrada'}), 404

@app.route('/tarefas/', methods=['DELETE'])
def deletar_tarefa(id):
    """Remove uma tarefa pelo ID"""
    global tarefas
    tarefas = [t for t in tarefas if t['id'] != id]
    return jsonify({'mensagem': 'Tarefa removida com sucesso'}), 200

if __name__ == '__main__':
    app.run(debug=True, port=5000)

Explicação do código:

  • @app.route define os endpoints (URLs) da API
  • GET /tarefas → lista todas as tarefas
  • POST /tarefas → cria uma nova tarefa (recebe JSON com titulo)
  • PUT /tarefas/<id> → atualiza uma tarefa (pode mudar título ou status)
  • DELETE /tarefas/<id> → remove uma tarefa
  • Os dados ficam em memória (quando o servidor reiniciar, os dados somem – depois você pode adicionar banco de dados)

Passo 5: Rode o backend

  1. Com o app.py aberto, clique no botão de run ▶️ no canto superior direito (ou pressione Ctrl + F5)
  2. O Flask vai iniciar o servidor em http://127.0.0.1:5000
  3. Abra seu navegador e acesse http://127.0.0.1:5000/tarefas – você verá uma lista vazia []

Se quiser testar a API, você pode usar o Postman, Insomnia ou o próprio terminal com curl. Mas não precisa – o frontend vai consumir a API.

Passo 3: JavaScript – a interação com a API

No arquivo frontend/script.js:

// URL da API (backend Flask)
const API_URL = 'http://127.0.0.1:5000/tarefas';

// Elementos DOM
const inputTarefa = document.getElementById('input-tarefa');
const btnAdicionar = document.getElementById('btn-adicionar');
const listaTarefas = document.getElementById('lista-tarefas');
const statusDiv = document.getElementById('status');

// Carrega as tarefas ao iniciar a página
document.addEventListener('DOMContentLoaded', carregarTarefas);

// Adiciona evento de clique no botão
btnAdicionar.addEventListener('click', adicionarTarefa);

// Adiciona evento de "Enter" no input
inputTarefa.addEventListener('keypress', (e) => {
  if (e.key === 'Enter') {
    adicionarTarefa();
  }
});

/**
 * Busca todas as tarefas da API e renderiza na tela
 */
async function carregarTarefas() {
  try {
    const response = await fetch(API_URL);
    if (!response.ok) throw new Error('Erro ao carregar tarefas');
    const tarefas = await response.json();
    renderizarTarefas(tarefas);
    atualizarStatus(tarefas);
  } catch (error) {
    console.error('Erro:', error);
    statusDiv.textContent = '❌ Erro ao carregar tarefas. Verifique se o backend está rodando.';
  }
}

/**
 * Envia uma nova tarefa para a API
 */
async function adicionarTarefa() {
  const titulo = inputTarefa.value.trim();
  if (!titulo) {
    alert('Digite uma tarefa!');
    return;
  }
  try {
    const response = await fetch(API_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ titulo })
    });
    if (!response.ok) throw new Error('Erro ao adicionar tarefa');
    const novaTarefa = await response.json();
    inputTarefa.value = '';
    carregarTarefas(); // recarrega a lista
  } catch (error) {
    console.error('Erro:', error);
    alert('❌ Não foi possível adicionar a tarefa.');
  }
}

/**
 * Marca/desmarca uma tarefa como concluída
 */
async function alternarConcluida(id, concluidaAtual) {
  try {
    const response = await fetch(`${API_URL}/${id}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ concluida: !concluidaAtual })
    });
    if (!response.ok) throw new Error('Erro ao atualizar tarefa');
    carregarTarefas(); // recarrega
  } catch (error) {
    console.error('Erro:', error);
    alert('❌ Não foi possível atualizar a tarefa.');
  }
}

/**
 * Remove uma tarefa
 */
async function deletarTarefa(id) {
  if (!confirm('Tem certeza que deseja deletar esta tarefa?')) return;
  try {
    const response = await fetch(`${API_URL}/${id}`, {
      method: 'DELETE'
    });
    if (!response.ok) throw new Error('Erro ao deletar tarefa');
    carregarTarefas(); // recarrega
  } catch (error) {
    console.error('Erro:', error);
    alert('❌ Não foi possível deletar a tarefa.');
  }
}

/**
 * Renderiza a lista de tarefas no DOM
 */
function renderizarTarefas(tarefas) {
  if (tarefas.length === 0) {
    listaTarefas.innerHTML = '
  • 🎉 Nenhuma tarefa! Adicione uma acima.
    • ';
    return;
  }
  listaTarefas.innerHTML = tarefas.map(tarefa => `
    
  • 
      
        ${tarefa.titulo}
      
      
    
        
        
      
    
    
    • 
  `).join('');
}

/**
 * Atualiza o contador de tarefas
 */
function atualizarStatus(tarefas) {
  const total = tarefas.length;
  const concluidas = tarefas.filter(t => t.concluida).length;
  statusDiv.textContent = `📊 Total: ${total} | Concluídas: ${concluidas} | Pendentes: ${total - concluidas}`;
}

    🐛 DEBUGGING INTEGRADO – FRONTEND E BACKEND JUNTOS

    Debugando o backend (Flask)

    1. No app.py, coloque breakpoints clicando na margem esquerda
    2. Pressione F5 ou clique no ícone 🐛 e selecione “Python Flask”
    3. O VSCode inicia o Flask em modo debug
    4. Quando o frontend fizer uma requisição, o código para nos breakpoints
    5. Você pode inspecionar variáveis, executar passo a passo, etc

    Debugando o frontend (JavaScript)

    1. Abra o DevTools do navegador (F12 no Chrome/Edge, Option+Command+I no Mac)
    2. Vá para a aba “Sources” (ou “Depurador”)
    3. Encontre o script.js e coloque breakpoints
    4. Recarregue a página ou interaja com a aplicação
    5. O navegador para nos breakpoints e você pode inspecionar variáveis
