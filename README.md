## 🎯 O que é este projeto? (em 1 minuto)

Este repositório contém um **site de material didático completo** para ensinar **programação web** (HTML, CSS e JavaScript) e **cultura digital** a estudantes do Ensino Médio, ao longo dos **3 anos**.

Pense nele como um **livro do professor em formato de site**. Em vez de PDFs soltos, o professor encontra:

- 📅 **Planos de aula prontos**, semana a semana (40 semanas por ano);
- 🧠 **Atividades práticas** com nomes divertidos, como *"Operação Tapa na Cara do Feio"* e *"Caça ao Elemento"*;
- ⏱️ **Roteiros minuto a minuto** para aulas de 50 minutos;
- 📊 **Rubricas de avaliação** prontas para usar;
- 📜 **Mapeamento das habilidades da BNCC** que cada aula desenvolve;
- ♿ **Orientações de inclusão e adaptação** para turmas diversas.

> **Resumo da ideia:** os alunos aprendem a **programar** e, ao mesmo tempo, aprendem a **questionar a internet**: como os algoritmos funcionam, por que seus dados valem dinheiro e como não ser apenas um consumidor passivo.

---

## 🧩 Qual problema ele resolve?

Existem dois problemas comuns no ensino de tecnologia na escola:

| Problema | Como este projeto responde |
|---|---|
| Aulas de programação **sem contexto**: o aluno aprende `<div>` e `for`, mas não sabe *por quê*. | Cada linguagem é ensinada dentro de um **projeto com propósito** (combater fake news, proteger a privacidade, cuidar do bem-estar digital). |
| Aulas sobre "uso consciente da internet" **só teóricas**: o aluno ouve o sermão, mas não *constrói* nada. | O aluno **entende o problema e depois programa uma solução**. |
| Falta de material **alinhado à BNCC** e ao Referencial Curricular do Paraná. | Cada semana já traz as **habilidades (códigos EM13...)** mapeadas. |
| Professor sem tempo para planejar 40 aulas por ano. | Planos, atividades, rubricas e cronograma **já estão prontos**, e podem ser adaptados. |

## 🧟‍♂️ A ideia central: de zumbi a arquiteto

Todo o material gira em torno de uma **narrativa** inspirada no filme *Matrix*. Ela existe para engajar os alunos:

```
   ZUMBI DIGITAL  ──────────────►  PRODUTOR  ──────────────►  ARQUITETO DIGITAL
 (só consome, rola o feed,        (entende como a internet     (cria soluções, projetos
  aceita todos os termos)          funciona por dentro)         e manifestos com código)
```

O texto de abertura do 1º ano resume a proposta: os alunos vão **passar de produto a produtor, de consumidor a criador**.

Por isso o material tem um tom **bem-humorado, irônico e provocativo**. O objetivo é prender a atenção de adolescentes, sem perder o rigor pedagógico.

## 🗓️ A jornada de 3 anos

### 1º Ano: *"Aprender a construir e descobrir como a Matrix funciona"*

O 1º ano ensina **as bases da programação web** e, depois, abre a "caixa-preta" das redes sociais.

| Bimestre | Nome | Foco |
|---|---|---|
| 1º | **Codando o Futuro** · *a construção do castelo digital* | HTML, CSS, JavaScript, DOM, eventos, arrays e funções, fechando com um projeto integrador. |
| 2º | **Revolução dos Dados** · *a desconstrução da Matrix* | Algoritmos de recomendação, dados pessoais, economia da atenção, fake news, LGPD e cyberbullying. |
| 3º | **A Queda da Matrix** · *hackeando o sistema* | Aprofundamento crítico: viés algorítmico, dopamina, bolhas, direitos digitais e um **protótipo** com apresentação estilo *Shark Tank / Demo Day*. |
| 4º | **O Despertar dos Criadores** · *a execução* | Os alunos planejam, constroem, depuram e apresentam um projeto completo, usando tudo o que aprenderam. |

**Exemplo: as 10 semanas do 1º bimestre**

| Semana | Aula | Atividade principal |
|:-:|---|---|
| 1 | O Universo HTML: A Estrutura do Nada | Construir a primeira página HTML coletiva |
| 2 | CSS: A Maquiagem dos Deuses | *"Operação Tapa na Cara do Feio"* |
| 3 | JavaScript: A Mágica Acontece | *"Gerador de Desculpas Esfarrapadas"* |
| 4 | DOM: O Documento que Vive | *"Caça ao Elemento"* |
| 5 | Eventos: Quando o Usuário Toca na Tela | *"Jogo da Memória do Caos"* |
| 6 | Dados e Arrays: A Biblioteca do Caos | Lista de tarefas (*to-do list*) |
| 7 | Funções que Fazem a Festa | Calculadora interativa |
| 8 | Projeto Integrador: Do Rascunho à Obra-Prima | Planejar e iniciar o projeto |
| 9 | Testes, Debug e Ajustes: O Martelo e a Bigorna | *"Caça ao bug"* |
| 10 | Lançamento Oficial: A Grande Estreia | Apresentações e certificados |

**Exemplo: as 10 semanas do 2º bimestre (cultura digital)**

| Semana | Aula | Atividade principal |
|:-:|---|---|
| 1 | O Algoritmo Invisível | *"Quem Manda no Feed?"*: os alunos **viram o algoritmo** e decidem o que mostrar a cada perfil |
| 2 | Dados: O Novo Petróleo | *"Caça aos Dados"*: listar tudo o que se sabe sobre si mesmo |
| 3 | A Economia da Atenção | Trechos de documentário + debate sobre gatilhos emocionais |
| 4 | Bolhas, Vieses e Fake News | *"Caça à Fake News"*: analisar posts reais |
| 5 | LGPD e Privacidade | *"Julgamento Digital"*: simulação de casos de violação de dados |
| 6 | Netiqueta e Cyberbullying | *"Teatro do Cyberbullying"* |
| 7 | Protótipo da Conscientização | Planejamento do protótipo |
| 8 e 9 | Mão na Massa (partes 1 e 2) | Desenvolvimento do protótipo |
| 10 | A Grande Estreia | Apresentação final |

### 2º Ano: *"Criar o mundo digital que você quer ver"*

No 2º ano os alunos deixam de ser só estudantes e viram **construtores de um projeto completo**, do zero, com **HTML, CSS e JS puros (sem frameworks)** e **com propósito**.

- Cada grupo escolhe **um problema real** da cultura digital (vício em redes, fake news, cyberbullying, privacidade, vigilância).
- Planeja um **MVP** (produto mínimo viável) aplicando os 4 Pilares do Pensamento Computacional.
- Constrói a aplicação ao longo das 10 semanas do bimestre: **planejamento → HTML → CSS → JavaScript → DOM → eventos → arrays → funções → debug → lançamento**.
- Os bimestres seguintes revisitam os temas de cultura digital (algoritmo invisível, dados como petróleo, fábrica de dopamina, bolhas, LGPD, netiqueta) e novas rodadas de projeto.

### 3º Ano: *"Arquitetos do Futuro Digital"*

O 3º ano é o **fechamento do ciclo**. Os alunos retomam o ciclo completo de planejamento, HTML, CSS, JS, DOM, eventos, dados, funções, debug e lançamento, com mais autonomia, e entregam um **produto final no ar**.

- A apresentação final segue o formato **Shark Tank**: *pitch* de 3 minutos, demonstração ao vivo, perguntas da banca, autoavaliação e premiação.
- O tom do ano é de **despedida e de protagonismo** (os bimestres seguintes têm o tema *"A Última Janela"*).

## 🔍 Anatomia de uma aula

Todo plano de aula segue **o mesmo padrão**. Assim o professor aprende a "ler" uma vez e usa nas 120 aulas.

| Seção | Para que serve |
|---|---|
| 🎯 **Título** | Nome da aula (e um subtítulo divertido). |
| 🎯 **Objetivos operacionais** | O que o aluno será capaz de **fazer** ao final. |
| 📚 **Conteúdo programático** | Os tópicos que serão ensinados. |
| 🧩 **Pilares do Pensamento Computacional** | Quais pilares a aula trabalha e como. |
| 📜 **Habilidades BNCC e RCP-PR** | Códigos oficiais (ex.: `EM13MAT101`, `EM13LP01`, `EM13CO07`). |
| ⏱️ **Detalhamento minuto a minuto (50 min)** | Roteiro cronometrado (`0-5 min`, `5-10 min`, `10-25 min`...). |
| 📋 **Atividade principal** | A prática "mão na massa". |
| 📊 **Avaliação** | Critérios com pontuação (ex.: *Estrutura básica 0-3*, *Indentação 0-1*). |
| ♿ **Adaptações e inclusão** | Sugestões práticas para turmas diversas. |

> 🖨️ As páginas têm botão para **imprimir ou salvar em PDF**, útil para levar o plano para a sala de aula.

## 🧠 Os 4 Pilares do Pensamento Computacional

Todas as aulas trabalham os **4 pilares**, que são formas de pensar para resolver problemas, dentro ou fora do computador:

| Pilar | O que significa | Exemplo no projeto |
|---|---|---|
| 🎭 **Abstração** | Focar no que importa e esconder o resto. | O HTML representa uma página de forma estruturada, escondendo a complexidade do navegador. |
| 🧱 **Decomposição** | Quebrar um problema grande em partes pequenas. | Dividir a página em cabeçalho, menu, conteúdo e rodapé. |
| 🔁 **Reconhecimento de padrões** | Perceber o que se repete. | Toda tag que abre (`<tag>`) precisa fechar (`</tag>`). |
| 📝 **Algoritmos** | Escrever o passo a passo da solução. | Uma função JavaScript que sorteia uma desculpa da lista. |

## 📜 Alinhamento com a BNCC e o RCP-PR

Cada aula traz as habilidades que desenvolve, organizadas por área:

- **Matemática e suas Tecnologias** (`EM13MAT...`): interpretação de dados, funções, modelagem, raciocínio lógico.

Além da BNCC, o material considera o **Referencial Curricular do Paraná (RCP-PR)** e as diretrizes de **Educação Digital e Midiática** (Resolução CNE/CEB nº 2/2025).

## 📊 Como a avaliação funciona

A avaliação é **contínua e por rubricas**, ou seja, o aluno sabe de antemão o que será avaliado.

### Visão anual (1º ano)

| Dimensão | Peso no ano |
|---|:-:|
| 🙋 Participação e engajamento | **20%** |
| 💻 Desenvolvimento técnico (HTML, CSS, JS, qualidade do código) | **40%** |
| 🧠 Pensamento computacional | **20%** |
| 🎤 Projetos e apresentações | **20%** |

Cada critério tem **4 níveis**: *Excelente (10)*, *Bom (7)*, *Regular (5)* e *Insuficiente (3)*.

### Visão por bimestre

Cada bimestre vale **25% da nota anual** e é pontuado de **0 a 10**.

| Bimestre | Exemplos de critérios |
|---|---|
| 1º | Atividades práticas de HTML/CSS/JS, projeto integrador, apresentação final |
| 2º | Participação e debate, análise crítica, atividades práticas, projeto de conscientização |
| 3º | Compreensão crítica, debate, atividades práticas, projeto revolucionário |
| 4º | Planejamento, desenvolvimento técnico, debug e polimento, apresentação, autoavaliação |

    ├── 📂 css/                      ← Um CSS por página (utfpr.css, ano1.css, ano1bim1.css, vscode.css…)

## 💻 Como rodar o site no seu computador

O site é **estático** (somente HTML, CSS e JS). Não precisa de servidor, banco de dados nem instalação complicada.

### Opção 1: a mais simples

1. Baixe o repositório (botão verde **Code → Download ZIP**) e extraia.
2. Abra o arquivo `index.html` com duplo clique.
3. Pronto, o site abre no navegador.

### Opção 2: com Live Server (recomendada para editar)

1. Instale o [VS Code](https://code.visualstudio.com/).
2. Instale a extensão **Live Server**.
3. Abra a pasta do projeto no VS Code.
4. Clique com o botão direito em `index.html` → **Open with Live Server**.
5. A página recarrega sozinha cada vez que você salva uma alteração.

### Opção 3: clonando com Git

```bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
cd NOME-DO-REPOSITORIO
```

> 🌐 Para publicar online de graça, use o **GitHub Pages** (*Settings → Pages → Deploy from a branch*).

## 🛠️ Tecnologias usadas no próprio site

O site foi feito para ser simples de manter:

- **HTML5** (estrutura semântica, `lang="pt-BR"`);
- **CSS3** (um arquivo por página);
- **JavaScript puro** (um arquivo por página);
- **[Bootstrap 5.3.2](https://getbootstrap.com/)** via CDN, apenas como apoio à responsividade;
- **Sem frameworks pesados e sem etapa de build.**

> 🎓 Isso é proposital: o próprio site serve de **exemplo do que os alunos aprenderão a construir**.
